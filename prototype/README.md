# exchange-watcher — прототип

Read-only мониторинг обмена с 1С. Читает CSV-лог обмена, применяет правила
свежести и ошибок, печатает отчёт и алерты в Telegram.

## Требования

- Python 3.9+
- без внешних зависимостей

## Быстрый старт

```bash
# 1. Первый прогон «как есть», фиксируем время 12:30
python3 monitor.py --now 2026-10-23T12:30:00 --no-state

# 2. Прогон с сохранением состояния — алерты дедуплицируются
rm -f state.json
python3 monitor.py --now 2026-10-23T12:30:00

# 3. Тот же момент, state.json уже есть — новых алертов нет
python3 monitor.py --now 2026-10-23T12:30:00

# 4. «Через час» — видно эскалацию по другим направлениям
python3 monitor.py --now 2026-10-23T13:30:00
